# 隐私政策

**上班鼓励器（GetPaidLive）· 生效日期 2026-11-04**

## 一句话

你填的所有东西——月薪、上下班时间、午休、发薪日、工作日、节假日、鼓励语——**全部只存在你自己的电脑里，不会上传到任何服务器**。程序没有账号、没有云端、没有后台，作者也没有任何办法看到你的数据。

## 数据存在哪里

只有一个目录：

```
%LOCALAPPDATA%\ShangBanGuLiQi\
```

等价路径是 `C:\Users\<你的用户名>\AppData\Local\ShangBanGuLiQi\`。里面是：

| 文件 / 内容 | 用途 |
|---|---|
| `data.db` | SQLite 数据库。薪资、工作时间、午休、发薪日、每周上班日、节假日与补班日、鼓励语商品表、日历备注、界面主题、窗口大小、桌面选项（开机启动 / 到点提醒 / 启动时查更新） |
| WebView 运行时数据 | 界面用 Windows 自带的 WebView2 渲染，它的本地存储也指向这个目录（`private_mode=False`），只用来记住界面状态 |
| 其余缓存文件 | 同目录下由 WebView2 自动产生，可随时删除，不影响数据 |

除此之外，程序只在系统里写一处与数据无关的东西：

- **开机自动启动**：开启后写注册表 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`（值名 `ShangBanGuLiQi`），内容就是 exe 的路径。关掉开关会立即删除这一项。

程序不创建任何日志文件，不写事件查看器，不往 `%TEMP%` 丢缓存。

## 程序会联网吗

只有两种情况会发出网络请求，都不是上传数据：

**1. 检查更新（可以关掉）**

启动时（以及每次打开设置里的「关于」页）会向 GitHub 查一次最新版本号：

```
GET https://api.github.com/repos/yoea/get-paid-live/releases/latest
User-Agent: ShangBanGuLiQi/<版本号>
```

- 请求里**只有版本号**，没有任何配置、薪资、使用记录或设备信息
- GitHub 作为服务器，和任何网站一样，必然能看到你的 IP 地址——这是 HTTP 请求的最低限度，程序无法避免也无法额外控制
- 想彻底不联网：`设置 → 桌面 → 启动时检查更新` 关掉。关掉之后程序在任何时候都不会主动发出请求

**2. 你主动点链接时**

「关于」页里的源码、许可、隐私政策、提交 issue、下载新版这些链接，都是交给系统默认浏览器打开的。请求由你的浏览器发出，走你自己的网络与浏览历史，与本程序无关。

## 程序不会做的事

- ❌ 不上传、不备份、不同步任何你的数据
- ❌ 没有账号体系，不要求登录、不需要邮箱手机号
- ❌ 没有埋点、统计、崩溃上报、A/B 实验
- ❌ 不读取你的其他文件，不截屏，不读剪贴板，不监听键盘
- ❌ 不向你推送广告，不采集设备指纹，不绘制用户画像
- ❌ 不向任何第三方出售、共享、披露数据（因为根本没有数据可披露）

## 你的数据，你说了算

- **查看**：`设置 → 关于 → 数据`，点一下直接用资源管理器打开那个目录，`data.db` 可以用任何 SQLite 工具查看
- **清空**：设置面板底部的「重设」，会清掉配置、备注、商品表，回到首次引导
- **彻底删除**：直接删掉整个 `%LOCALAPPDATA%\ShangBanGuLiQi\` 文件夹。卸载程序不会自动删它——这是有意的，免得升级或重装时把你的配置弄丢。删掉之后，这台电脑上再无任何残留

## 儿童

本程序不面向儿童，也不收集任何年龄、身份信息。它只是一个把月薪换算成秒薪的本地计时器。

## 政策变更

本文件随代码一起放在公开仓库里，每次修改都留在 git 提交历史中，可以随时[查看改动记录](https://github.com/yoea/get-paid-live/commits/main/docs/PRIVACY.md)。如果将来真的加入了任何联网功能，会先在这份文件里写清楚，并在 Release 说明里注明。
